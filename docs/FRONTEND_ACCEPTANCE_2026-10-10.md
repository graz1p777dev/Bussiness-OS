- Для роли без действий кнопки экспорта, импорта и восстановления отключены. Дополнительно вызван реальный `change` обработчик file input с тестовым File: импорт получил «Недостаточно прав: Внешний вид / accent», preview не открылся, запись не изменилась.

## Проверенная связь с прежними проектами

Источники — три локальных проекта DemiResults, SmileKit и ранее выполненный read-only срез актуального VPS. Конкретные различия и серверные пути перечислены в `FRONTEND_AUDIT.md`; этот аудит заново production не обходил.

В frontend представлены выявленные страницы/поля: CRM-фильтры и этапы; product/service/kit, isFreePrice, EAN-13, складские документы с черновиком/проведением; money ledger, POS/смена/возврат; публичная витрина и её заказы; ru/ky inventory-navigation; партнёры; табель/личное время; командный messenger; SmileKit prompts/rules/hypervisor. Их прежние UI-результаты следует читать в истории аудита, а не считать все заново исполненными 10 октября.

Не приписывать оригиналу неподтверждённую функциональность: наличие таблицы kit items на VPS не доказывало работающий редактор BOM; shop-order RPC создаёт заявку без резервирования/списания остатков. Локальный перенос сохраняет эти установленные границы.

## Что остаётся непроверенным либо требует другого слоя

1. Отправка в Git подтверждается отдельно результатом push. Последнее совмещённое состояние: 300 frontend-тестов проходят, TypeScript и production build успешны; lint 0 ошибок / 19 предупреждений. Сотрудник 5175 синхронизирован. Backend: 38 passed, 2 PostgreSQL concurrency tests skipped.
2. Полный повторный UI-проход Publisher/MCP и history sanitizer после смены прав. Sanitizer и actor override проверены кодом/тестами, но это не полная браузерная матрица ролей. Новые поля AgentConfiguration, компоновка Dashboard и последние инструменты календаря/оформления Assistant уже проверены UI в этом срезе.
3. Нативный выбор JSON-файла на диске, физический принтер/сканер штрихкодов, микрофон и разрешение MediaRecorder, реальное слабое устройство. Код этих возможностей не равен аппаратному тестированию.
4. Настоящие каналы WhatsApp/Telegram/Instagram, доставка сообщений, webhook, платежи, облачная синхронизация, LLM/internet, фоновые расписания, реальный MCP transport/credentials, developer identity/subscription/security review, мониторинг и ремонт production — не исполнялись этим frontend-аудитом.
5. Настоящая auth/session/server-side RBAC, межарендаторская изоляция, транзакции БД, stock concurrency, серверное хранение файлов/секретов/паролей и системный аудит проверяются отдельно в backend. Наличие `business-os-backend` и его API-тестов не означает подключение этого слоя ко всем frontend-страницам.

Подробные серверные обязательства: `docs/BACKEND_HANDOFF.md`, `docs/BACKEND_IMPLEMENTATION_PLAN.md`. Отсутствующая телеметрия, внешняя модель или история звонков обозначены как отсутствующие, а не заменены выдуманными результатами.
